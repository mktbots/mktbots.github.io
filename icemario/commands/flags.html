Custom Flags Manager

Custom flags manager. Allows people to add or remove flags to be used when creating a table.

Message commands, like !flagadd, !flagremove, !flaglist, and !flagget will continue to work like before.

/flag add-or-edit

name (required): The flag's name. This can be at most 10 characters, and it can only include letters a-z, numbers, underscore, and a dash.
flag-attachment: The flag as an attachment.
flag-url: The flag as a url.

Add or edit a flag.

While flag-attachment and flag-url are not listed as required on the slash command, you must provide one of them in order to update a flag.

/flag remove

name: The name of a flag.

Used to remove a flag.

/flag get

name: The name of a flag.

Get an image of the specified flag. This can either be a custom flag or an Hlorenzi flag.

/flag list

List all the flags that have been added to the bot. Press the buttons at the bottom to toggle between the respective pages.
