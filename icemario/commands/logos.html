Custom Logos Manager

Custom logos manager related to the table maker.

Some message commands, like !logoget, !logoadd, !logoremove, and !logolist will continue to work like before, but slash commands are preferred since they can be better customized.

The following commands have been removed: !logocolor, !logocategory, !logolock, and !logounlock. Instead, use the /logo add-or-edit command to update these settings.

/logo add-or-edit

name (required): The logo's name. This can be at most 10 characters, and it can only include letters a-z, numbers, underscore, and a dash.
logo-attachment: The logo as an attachment. Only required if changing the logo itself.
logo-url: The logo as a url. Only required if changing the logo itself.
category: The logo's category. Default: unsorted.
color: The logo's color. Either a single hex color or a gradient (#FF0000 #0000FF /). Enter #FFFFFF to remove.
lock: If yes, future logo changes can only be made in the server the command was used.
font: The default font for all text for the team.
font-clan-score: The font for the team's total score.
font-clan-rank: The font for the team's rank.
font-player: The default font for the team's players' name, score, and rank.
font-player-name: The font for the teams' players' name.
font-player-score: The font for the teams' players' scores.
font-player-rank: The font for the teams' players' rank.

Add or edit a team's logo.

If you need to add or edit the logo itself, either logo-attachment or logo-url is required. Otherwise, if you only need to change a logo's property, like the category or font, those two options can be left blank.

Please don't lock a logo unless absolutely necessary since it can cause them to become outdated.

For fonts, select one of the autocomplete options, and to remove one, select the delete option.

/logo remove

name: The name of a team.

Used to remove a logo.

/logo get

name: The name of a team.

Get the logo for the team. This will also list all the set properties for the logo, like category, color, and any fonts.

/logo list

category (optional, default: unsorted): Valid categories are: mkt, mkt2, mk8dx, world, wc, 200cc, or unsorted.
use-image (optional, default: Yes): If Yes, display the logo images. If No, list the logos as text.

List all the logos that have been added to the bot. Use the select menu to toggle between the categories, and for categories with many logos, press the buttons to get the respective page.
